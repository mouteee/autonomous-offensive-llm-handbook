# Audited mechanism claims, one per claim-bearing docstring.
#
# Format:  <path>::<name>@<hash>  # <VERDICT>: <the mutation, and what was OBSERVED>
#
# <name> is the function, class or method the docstring belongs to, or
# <module> for a module docstring. <hash> is _doc_digest's sha1 prefix over the
# docstring's reflowed text, so a row is keyed by the WORDS it audited and not
# by where they sit: re-wrap a docstring and the row stands; reword it and the
# census re-opens the audit and names the row. A shell row is keyed the same way
# by _block_key, with a slug of its opening words in place of the symbol name.
# Before that hash existed, a row's identity was a docstring's location, and a
# rewritten claim carried the old verdict over silently. A blank line or a line opening with # is a
# comment. Every claim-bearing docstring under the Python globs in
# _SWEPT_GLOBS -- tests/, core/, scripts/ and walkthrough/ -- must appear here or
# test_every_mechanism_claim_has_been_audited fails and names it: an unaudited
# claim is the failure, not a warning.
#
# TRUE      -- the mutation the docstring describes was applied to a copy of the
#              tree and the named behaviour changed as claimed. THE OBSERVABLE IS
#              PART OF THE VERDICT: what was run, and what came back. A bare
#              "TRUE" is a claim about a claim, which is the thing this file
#              exists to stop.
# TRUE (reasoned, not run) -- the claim was checked against source by reading and
#              no mutation was executed. Recorded this way on purpose, so a
#              verdict that was argued is never mistaken for one that was
#              measured.
# [unswept] -- appended to the verdict for a docstring the census CANNOT see: one
#              carrying none of CLAIM_RE's verbs, which the walker sweeps and the
#              regex passes over. Such a claim used to be unauditable rather than
#              merely unaudited -- a row written for it failed the orphan arm as
#              "audited claims that no longer exist", about a docstring sitting in
#              the tree. The tag is not an exemption. The row still has to name a
#              docstring present right now, byte for byte, because the key carries
#              the reflowed-text hash: reword the docstring and the row stops
#              resolving and returns as a genuine orphan. It also has to name one
#              the census truly cannot see, so a real claim cannot be parked out of
#              the machine's reach. Both directions fail loudly; see the row for
#              _docstring_keys, which is the first claim audited this way and is
#              its own worked example.
# CORRECTED -- the mutation showed the docstring wrong; the docstring was fixed,
#              never the assertion, and the line records what changed. The one
#              exception is noted where it happens: for the stdlib-only claim the
#              honest fix was to add the assertion the docstring already
#              promised.
#
# AND NEITHER MAY A UNIVERSAL QUANTIFIER OVER A FILE. "takes the whole file down", "the rest

# claims about a population that the next commit changes, and the rule above bans only the numeric
